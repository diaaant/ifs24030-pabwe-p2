# NexaMind AI — PABWE Praktikum 2

Website studi kasus perusahaan jasa Artificial Intelligence untuk PABWE Praktikum 2.

## Halaman
- `index.html` — Landing Page perusahaan jasa AI, CSS murni + external CSS.
- `blog.html` — Daftar blog AI, Bootstrap 5 + Bootstrap Icons.
- `blog-detail.html` — Detail artikel AI, Bootstrap 5 + Bootstrap Icons.
- `cv.html` — CV digital, Tailwind CSS 4 Play CDN.

## Struktur
```text
nexamind-pabwe-p2/
├── index.html
├── blog.html
├── blog-detail.html
├── cv.html
├── README.md
└── assets/
    ├── css/
```

## Catatan
Semua halaman saling terhubung melalui navigasi. Landing page menggunakan CSS eksternal tanpa Bootstrap/Tailwind; blog memakai Bootstrap 5 dan Bootstrap Icons; CV memakai Tailwind CSS 4 Play CDN.
